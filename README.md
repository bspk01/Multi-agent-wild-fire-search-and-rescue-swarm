# FIRE-SAR — Multi-Agent Wildfire Search, Survivor Tracking and Adaptive Rescue Coordination

**AI3403 – Multi-Agent Systems | IIT Hyderabad**

FIRE-SAR is a decentralized Multi-Agent System for coordinating heterogeneous UAVs, survivors, and limited rescue resources in a dynamic wildfire environment.

### Planned System
- Heterogeneous UAV-based survivor search and tracking
- Dynamic UAV communication and task allocation
- Independent survivor behaviour and group fragmentation
- RL-based high-level UAV task allocation
- Optimization-based rescue resource allocation
- Failure handling and adaptive task reallocation
- STL-based safety and mission requirements
- Real-time 2-D simulation and evaluation
